# Учебный проект по Python

## Описание:

Проект готовит данные для отображения в новом виджете.

Созданы функции:

- для обработки информацию о картах и счетах, возвращает строку с замаскированным номером;
- Функция, которая форматирует дату в формате ДД.ММ.ГГГГ;
- Функция принимает список словарей и опционально значение для ключа и возвращает новый список словарей,
    содержащий только те словари, у которых ключ state соответствует указанному значению;
- Функция, которая принимает список словарей и необязательный параметр,
    задающий порядок сортировки (по умолчанию — убывание) и возвращает новый список, отсортированный по дате.

## Установка:

### С использованием poetry (через SSH)

1. Клонируйте репозиторий:
```
git clone git@github.com:dancho-panso/test-repository.git
cd test-repository
```
2. Установите poetry (если еще не установлен):
```
pip install poetry
```
3. Активируйте виртуальное окружение:
```
poetry shell
```

## Тестирование:

Проведены тесты:
- test_masks.py (Модуль тестирования маскировки номеров карт и счетов отдельно)
- test_widget.py (Модуль тестирования маскировки карт и счетов, а так же преобразования дат)
- test_processing.py (Модуль тестирования фильтрации и сортировки данных)

Покрытие кода тестами: 99%

### Запуск тестов (для разработчиков)


# Установка зависимостей для тестирования
pip install pytest pytest-cov

# Запуск всех тестов с отчетом о покрытии
pytest --cov
pytest --cov=. --cov-report=term-missing

# Генерация HTML-отчета (откроется в браузере)
pytest --cov=. --cov-report=html
# Затем откройте файл htmlcov/index.html
